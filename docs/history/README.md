# History

Planning documents from the first drwho.me, April 2026, moved here from the Domain Posture
repository on 2026-09-22 when drwho.me became its own site.

drwho.me started as a Next.js free-tools site with an MCP endpoint. It grew into the domain
dossier and the paid evidence pack, was rebranded Domain Posture in June 2026, and the
free-tools-and-MCP part was split back out into this repository in September 2026. These files
describe the original product. The stack they name (Next.js, Vercel, `@vercel/mcp-adapter`)
is not the stack of this repository; read them for the product reasoning and the tool list,
not for implementation.
